# 06 · 角色协作

覆盖九步工作流 **⑦ 审校**。

**核心判断**：一次写作会话里，**立场会互相污染**。批评意见会渗进草稿，草稿会渗进记忆。所以角色隔离不是组织洁癖，是**质量控制手段**——这正是铁律五（批评者不能改稿）的由来。

---

## 1. 五个角色：职责与边界

| 角色 | 原项目 | 干什么 | 产出物 | **不干什么** |
|---|---|---|---|---|
| **编排者** | muse | 面对作者、理解意图、分派任务、**综合**各方结果、下判断、回话给作者 | 决策与综合结论 | 不转发原始报告当结论；不长期占用上下文写正文 |
| **写手** | writer | **独占产出**：初稿、修订、衔接段、变体、行内润色 | `正文/第NNN章.md` | 不更新追踪状态（那是编排者/追踪流程的活） |
| **批评者** | critic | 对抗式诊断，**一次只深挖一个焦点** | 批评报告（问题＋为什么伤读者＋怎么办＋严重度） | **只读**，不写正文、不写追踪 |
| **编辑** | editor | 第三方 holistic 审阅，给出**修订优先级**（整体诊断排在逐条问题前面） | 编辑备忘录 | **只读**，不重写（除非作者明确要求改写） |
| **读者模拟** | reader-sim | 以指定读者人设给**阅读体感**回应，不是技艺批评 | 读者信号（哪里爽、哪里断了、哪里想弃） | 不做技艺诊断、不改稿 |

### 编排者不是传声筒

编排者要**自己读**草稿和报告，综合冲突的意见，然后告诉作者：改了什么、什么还行、什么仍不放心、需要作者拍板什么。直接把三份报告堆给作者＝没干活。

### 写手独占产出：为什么

> 原话：*"One writer per scene — voice consistency degrades when multiple writers handle adjacent content."*

**一场戏一个写手。** 把初稿、衔接段、修订拆给不同的写手，声音一致性会崩——每个人对"这句话该多重"的判断不一样。**立场靠 prompt 切换**（初稿 / 外科式修订 / 衔接 / 润色 / 变体），**不靠换人来切**。

这一点对中文网文尤其致命：网文的"味道"高度依赖句长节奏和口头禅，两个人写相邻章节读者立刻能感觉出来。见 `09-批量写作.md` 的并行坑。

## 2. 权限矩阵

| 角色 | 读正文 | 写正文 | 读追踪 | 写追踪 | 产物落点 |
|---|---|---|---|---|---|
| 编排者 | ✅ | ❌ | ✅ | ✅ | 决策 / 综合结论 |
| **写手** | ✅ | **✅（独占）** | ✅ | ❌ | `正文/` |
| 批评者 | ✅ | **❌（硬禁）** | ✅ | ❌ | `审校/批评-N.md` |
| 编辑 | ✅ | **❌（硬禁）** | ✅ | ❌ | `审校/编辑备忘.md` |
| 读者模拟 | ✅ | **❌** | ❌ | ❌ | `审校/读者信号.md` |

**硬规则**
1. 批评者与编辑**一律只读**（原项目在 agent 定义里直接写 `edit: deny` / `write: deny`，sandbox 锁 `read-only`）。
2. 写手**独占**正文写入权。采纳哪条批评由写手决定——**采纳权**和**产出权**必须同在一处，否则稿子会被意见牵着走。
3. 读者模拟**不读追踪**（它要模拟的是"只读过正文的人"，读了状态就不准了）。

## 3. 为什么批评意见必须与草稿物理隔离

三条理由，都不是玄学：

| 理由 | 说明 |
|---|---|
| **防止批评污染草稿** | 批评者的表述是"诊断体"（问题、严重度、怎么办）。这种语域一旦进了写手的上下文，写出来的句子会带上**解释腔**——正是 `05-去AI味.md` §1 第 3、7 条 |
| **防止草稿污染记忆** | 未定稿的中间版本如果被写进追踪，就会把"某个角色可能死了"变成既成事实，后面全崩（与铁律四同源） |
| **保持对抗性** | 批评者需要在**干净的上下文**里读稿。它如果看着写手的思考过程读，会跟着写手的自我解释一起相信那是成立的 |

**物理隔离的做法**：批评意见**落盘到独立文件**（`审校/`），不贴在同一段对话里让写手边看边改。写手读的是**报告**，不是批评者的推理过程。

> 铁律五原文：*"让批评意见污染草稿、让草稿污染记忆，是长篇质量崩坏的两大通路。"*

## 4. 无子代理环境下的单智能体降级方案

没有子代理可派时，**一个人依次扮演全部角色**。难点不是能不能做，是**怎么不串味**。

### 4.1 分幕扮演（一次一个帽子，不混戴）

```
【幕 1 · 写手】  只开：细纲 + 上下文卡 + 风格文件      → 产出正文，写盘
   ⛔ 此刻不做任何评价，不回头挑自己的毛病
──────── 切换标记：把草稿写盘，清空"我在评价"的念头 ────────
【幕 2 · 批评者】 只开：正文 + 评判维度（本节 §5）       → 产出批评报告，写盘到 审校/
   ⛔ 此刻不许改正文一个字
──────── 切换标记：报告写盘 ────────
【幕 3 · 读者模拟】只开：正文（不读追踪、不读细纲）      → 产出读者信号，写盘
──────── 切换标记 ────────
【幕 4 · 编辑】  开：正文 + 批评报告 + 读者信号         → 产出优先级排序，写盘
──────── 切换标记 ────────
【幕 5 · 编排者】 开：全部报告                        → 综合，下决定：过了 / 回写手改哪几条
──────── 切换标记 ────────
【幕 6 · 写手】  开：正文 + 决定清单（**不重开报告**）   → 改稿
```

### 4.2 四条防串味纪律

| # | 纪律 | 为什么 |
|---|---|---|
| 1 | **每幕只喂该喂的文件** | 幕 6 改稿时不重读批评报告全文，只读"决定清单"。重读＝把诊断体灌回笔头 |
| 2 | **每幕产物落盘再换帽子** | 落盘是物理断点。不落盘＝两段立场在同一段上下文里糊在一起 |
| 3 | **批评报告用第三人称写，写给"别人"看** | 语气一旦变成自我检讨，下一幕就会写成自我辩护 |
| 4 | **改稿时按"决定清单"逐条打勾，不自由发挥** | 自由发挥＝写手和批评者同时在线，最易串味 |

### 4.3 最小降级（赶进度时）

只有两幕也能跑：**写手 → 批评者 → 写手**。
省略编辑与读者模拟，但**批评者一幕不能省**——省掉批评等于放弃审校，那才是真正的偷工。

## 5. 审校轮次与批评者数量的伸缩规则

批评者**按焦点并行**：结构 / 人物 / 声音 / 文笔 / 连续性（对应 `08-审校清单.md` 的五层）。不同焦点跑不同道，不是同一焦点跑五遍。

| 档次 | 适用 | 批评者数量 | 焦点分配 |
|---|---|---|---|
| **低风险 1–2** | 过渡章、日常章、纯推进章 | 1–2 | 只跑「连续性」+（可选）「人物」 |
| **标准章 3** | 常规章节 | **3** | 连续性 + 人物 + 声音（或文笔，按本章性质选） |
| **关键场次 4–5** | 高潮、揭露、死亡、感情转折、结局 | **4–5** | 五层全覆盖，并在**最关键那一层加一道重复覆盖** |

> 原话：*"1–2 for low-stakes, 3 for standard chapters, 4–5 for pivotal scenes with duplicated coverage on the critical dimension."*

**关键场次的"重复覆盖"**：关键那一层（例如揭露章的「连续性/信息差」）跑两个批评者，各自独立——一个用主模型，一个换另一个模型/另一个角度，然后由编排者综合**分歧**。分歧本身就是信息：两个人都说有问题，是真问题；只有一个人说，多半是口味。

### 编辑与读者模拟什么时候上

| 角色 | 时机 |
|---|---|
| **编辑** | 需要**跨维度排优先级**时上。只求某一层深度，用批评者就够 |
| **读者模拟** | **写—评循环收敛之后**、交给作者之前上。"技术上干净但读者无感"只能靠这一环发现 |
| **追踪更新** | 章定稿、决定拍板之后才做。不要在讨论过程中随手改状态 |

## 6. 可复制模板

### 6.1 批评报告（一条 findings 的写法）

```markdown
# 批评报告 · 第 NNN 章 · 焦点：{连续性}
> 只读产物。本文件不改正文。

## F1 · {一句话问题}　严重度：高 / 中 / 低
- **位置**：第 3 场，苏明回营之后那一段（"他解下佩剑……"起）
- **原文引用**：「……」
- **为什么伤读者**：上一章他剑已经断在石壁上，这里读者会以为他在藏
- **怎么办**（建议，采纳与否由写手定）：补一句断剑的处理，或改掉"解下佩剑"这个动作
```

> 编排者不看草稿就能据此定位——所以**引用必须具体到段落**。

### 6.2 决定清单（给幕 6 的写手用）

```markdown
# 第 NNN 章 · 决定清单
- [ ] F1（连续性·高）：断剑交代 —— 采纳，在"回营"段加一句
- [ ] F2（声音·中）：老周的台词太书面 —— 采纳，压成短句
- [ ] F3（文笔·低）：第 7 段三句排比 —— 不采纳，这里要的就是铺排
- [ ] 读者信号：中段想跳过 —— 不采纳，这一章的地形说明下卷要用
```

### 6.3 编排者综合结论（回给作者的话）

```markdown
第 NNN 章改完了。
- 改了：断剑交代、老周台词（2 处）
- 还行：揭露的节奏、结尾钩子
- 仍不放心：中段地形说明读者会跳，但下卷要回收，建议留着
- 需要你拍板：要不要把它压成半段？
```
