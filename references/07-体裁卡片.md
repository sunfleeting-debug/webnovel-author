# 07 · 体裁卡片

覆盖九步工作流 **① 立项（选赛道）→ ②③ 设定与卷纲 → ⑤ 写正文**。
一张卡只回答一个问题：**这个赛道到底在卖什么，读者凭什么往下翻。**

---

## 0. 用法（三条）

1. **一次只读一张卡**。主题材读完整卡；跨题材时辅题材只摘 1–2 条「必备桥段 / 常见坑」，别把两套节奏并排堆满。
2. **卡片只在写手内部校准题材味**。正文里不许出现卡名、题材标签、"按 XX 流的写法"这类词——同 `05-去AI味.md`。
3. **冲突优先级**：已定稿正文与细纲 > 体裁卡 > 本书文风 > 通用技巧。卡是参考，不是圣旨。

### 统一字段

| 字段 | 回答什么 | 用在哪一步 |
|---|---|---|
| 核心爽点公式 | 往下翻的那一口到底是什么 | 立项、每章收尾检查 |
| 节奏要求 | 多久给一次、单章几次、卷级怎么排 | 卷纲、细纲 |
| 力量/能力体系 | 怎么分级、怎么收放、上限在哪 | 设定（`设定/金手指.md`） |
| 常见坑 | 这个赛道稳定翻车的点 | 审校（`08-审校清单.md`） |
| 必备桥段 | 读者按约定长度期待看见的场面，缺了他会觉得"不像" | 卷纲排程 |

**每章收尾自查**：① 按本卡的爽点公式给过一次释放了吗；② 有没有**外部反馈**（有人看见主角变强并做出反应）；③ 有没有踩本卡常见坑的前三条。踩了直接进 `08-审校清单.md`。

## 1. 模拟 / 系统流（重点）

| 字段 | 内容 |
|---|---|
| **核心爽点公式** | **低起点 + 独家信息差（别人不知道，我知道）→ 当场做出反常识决策 → 结果验证 → 围观者态度反转。** 爽的不是"系统强"，是**主角握有一份别人没有的信息，并且敢下注** |
| **节奏要求** | 每章 ≥1 次小结算（提示/结算/签到结果）+ ≥1 次**外部反馈**（有人看见并反应）；每 3 章 1 次中型兑现；每卷 1 次规则升级或扩容。面板信息越长，现实反应越要具体，否则变成自嗨 |
| **力量体系怎么设计** | 面板只**记账**，不做**上限**。数值线性增长迟早崩，所以每 50–80 章把主角的**社会身份换一档**（学生→队长→堂主→执掌者），让"合法性"跟着升级。金手指分两条线：**信息线**（模拟预知/判定/提示）和**资源线**（结算奖励），前者造爽点，后者造成长，两条不许同时全开 |
| **常见坑** | ① 连续贴面板（写到第 3 屏就是注水）；② 系统替主角决策，主角失去主动性；③ 奖励无代价、无失败；④ 限制只写在设定里，正文从不兑现；⑤ "第五次模拟"这类**计数自己数错**（必须记进 §7 数值账目）；⑥ 金手指悬空展示，不落到现实凭据上 |
| **必备桥段** | 第一次结算 · 第一次在公开场合用信息差取胜 · 唯一性奖励公布 · 限时任务倒计时 · 系统提示异常（天然伏笔）· 结算结果与常识冲突（打脸现场）· 别人也想抢这个金手指 |

### 1.1 限制机制设计原则（本赛道成败所在）

没有限制的系统，第 20 章就没戏了——**读者爽的是"在限制里解题"，不是"开挂"。**

| 原则 | 说明 | 反例（等于没设计） |
|---|---|---|
| **限制要有形状** | 必须能被读者一句话复述："一天一次，一次三分钟""看不到超过自己两级的人" | "消耗少量精神力"——读者不知道多少，等于不限制 |
| **限制必须造成本次失败** | 正文里至少有一次，因为限制，主角**没做成事** | 写了"冷却 24 小时"，却从没在冷却里出过事 |
| **代价随收益换维度** | 收益翻十倍，代价要从时间→资源→关系→不可逆 | 全程只用"精神力不足"，后期必然失去张力 |
| **四个旋钮轮流拧** | 次数 / 代价 / 可见度（谁看得到）/ 失效条件（什么情况下无效） | 只拧"次数"这一个旋钮，很快调到无处可调 |
| **限制即钩子** | 每次受限，顺手埋下一次"突破这个限制"的期待 | 限制只是把主角卡住，不给出口 |
| **计数进官方账目** | 第几次模拟/抽取/签到必须写进 §7 的数值账目，逐章核对 | 正文写"第五次"，账目记第四次 |
| **限制不豁免人格** | 系统给不了的东西（判断力、担当、撒谎）必须由主角自己出 | 系统直接给标准答案，主角照做 |

## 2. 修仙 / 玄幻

| 字段 | 内容 |
|---|---|
| **核心爽点公式** | **资源稀缺 → 争夺 → 我比同阶更懂/更狠/更有机缘 → 越级是有代价的 → 上位者终于注意到我。** 爽点是**层级碾压的可视化**：一个小境界差要用具体东西演出差别（一招、一息、一件法宝） |
| **节奏要求** | 小境界 3–5 章，大境界 1–2 卷；每卷至少 1 次"越级斩杀"+ 1 次"被上位者碾压"（双向都给，拉满温差） |
| **力量体系怎么设计** | 境界可以无限，但每层要挂**硬指标**：寿元、一击之距、突破所需资源量、该层平均修炼年限。同阶内部用**流派 / 根骨 / 传承**拉开差异，否则同一境界里所有人长得一样。跨境界动手必须付出**看得见的代价**（寿元、道基、法宝损毁） |
| **常见坑** | 境界通胀（后期数字失控，读者无感）；同阶战斗写成互相报招名；资源单位（灵石/贡献点）前后价值不统一；底牌随手亮；"万年难遇的天才"每卷出一个 |
| **必备桥段** | 测灵根/废柴开局 · 坊市捡漏 · 秘境争夺 · 越级斩杀 · 师门大比 · 围杀反杀 · 闭关突破 · 老怪夺舍（伏笔常客）· 拍卖会压轴 |

## 3. 都市（含都市异能 / 商战 / 文娱）

| 字段 | 内容 |
|---|---|
| **核心爽点公式** | **被看轻 → 当场拿出无法被忽略的结果 → 围观者与权势的态度反转。** 都市的爽点必须落到**现实凭据**：钱到账、合同、体检报告、监控、热搜、鉴定结论 |
| **节奏要求** | 每章 ≥1 次现实反馈。金手指开场的**说明书不超过一段**，第三句就要回到角色反应 |
| **力量体系怎么设计** | 都市的力量是**可支配的社会资源**（钱、人脉、身份、信息）+ 一个金手指。等级用**社会位阶**表达（组长→总监→合伙人→圈子准入），不要做成纯数值——读者对"身价多少"的想象力远不如"能不能进那个门" |
| **常见坑** | 金手指悬空展示（先写三页面板）；反派降智送脸；主角口头报复不落地；金额随手写（一章百万、下章一亿）；现实规则（法律、审批、流程）该给交代时不给 |
| **必备桥段** | 开局窘境（欠债/退队/离婚/被辞）· 第一次当场翻盘 · 权威鉴定或检测结论 · 同学会、饭局、家族聚会的公开较劲 · 媒体与口碑反转 · 更高位者登场 · 圈层准入（内部名单、股东会门禁） |

## 4. 言情

| 字段 | 内容 |
|---|---|
| **核心爽点公式** | **一个不可能/不正当的关系起点 → 反复靠近与推开 → 每次靠近都有代价 → 一次不可逆的表白或牺牲。** 爽点是**关系温度的可见位移**（称呼、肢体距离、说话方式），不是发生了什么事件 |
| **节奏要求** | 用**关系档位**推进，不用事件数量。slow burn 每 8–12 章完成一次档位跃迁，每个档位至少 3 个可见 moment（见 §8 模板） |
| **力量体系怎么设计** | 角色的能力从属于**关系内的权力结构**：谁先低头、谁握着秘密、谁先失去退路。事业线只服务感情线，不许反过来顶掉主线推进 |
| **常见坑** | 靠"不说清楚"制造冲突（读者会觉得角色蠢，不是觉得难）；男主行为只用"他就是爱她"解释；误会拖过两章不澄清；配角全是工具人；HE 前突然黑化无铺垫 |
| **必备桥段** | 带身份差的初遇 · 被迫同桌/同居/契约 · 受伤照护 · 吃醋 · 为对方破例（违背自己的原则）· 第三者压力 · 分离或险些失去 · 公开承认关系 |

## 5. LitRPG / 游戏异界

| 字段 | 内容 |
|---|---|
| **核心爽点公式** | **数值的可见增长 + 战略的最优解 + 玩家思维碾压 NPC。** 双重兑现：既要看数字涨，也要看主角用别人不懂的玩法赢 |
| **节奏要求** | 面板只出现在**结算时刻**（升级、战斗结束、分配点数），战斗过程中不贴面板。每次升级必须有"这次的选择"，并紧接一次"被现实检验" |
| **力量体系怎么设计** | 六维基础属性 + 派生 + 技能/称号/词条三层。核心纪律：**总量恒定**——升级拿到的点数必须能算平（见 §7 账目）。同等级必须有明确战力基准，否则"打赢谁"失去意义 |
| **常见坑** | 连续章节贴面板；词库中英混用不统一；数值膨胀后再无对比对象（一千级的敌人和一万级的敌人读感一样）；系统名词（等级/生命值/经验）中文写法不统一；Bug 类能力用过就忘 |
| **必备桥段** | 初次生成面板 · 第一次杀怪升级 · 隐藏职业/稀有词条 · 首杀公告 / 排行榜公示 · 组队与贡献分配（天然冲突源）· 副本机制破解 · Bug/漏洞作为危机 |

## 6. 悬疑 / 脑洞

| 字段 | 内容 |
|---|---|
| **核心爽点公式** | **一个具体的不可能 → 每章给一个更深的解释并让旧解释失效 → 最终解释必须覆盖全部已投线索。** 爽点是**猜错的快感**：读者自己推理→被打脸→心服 |
| **节奏要求** | 每章至少回收 1 条小线索、抛出 2 个新疑点；每 3 章一次"旧解释崩塌"。悬疑靠**分配**信息，不靠隐瞒信息 |
| **力量体系怎么设计** | 主的能力是**推理力/规则发现力**。规则类脑洞（规则怪谈、无限流）的每条规则必须写成**可验证、可推翻**的句子，不许写"不要回头看"这种无法证伪的玄学条款 |
| **常见坑** | 用"他疯了/是场梦"收场；新角色出来一口气解释所有事；线索从不按时兑现；恐怖靠形容词堆；真相揭晓时读者才发现线索压根没给过 |
| **必备桥段** | 不可能的现场（密室/消失的尸体）· 第一条规则 · 违反规则的代价 · 信息错位导致的误判 · 中期伪解答崩塌 · 真相回溯（所有线索重现一遍）· 最后一个反转 |

## 感情线进度模板

> 取自 webnovel-free-mcp 的 `templates/romance-tracker.json`（九阶段 + 阻碍/吃醋/误会/热度），改成纯 Markdown。每一对 CP 一份，存 `设定/感情线/{A}×{B}.md`。

### 九阶段与出口条件

| 阶段 | 中文 | 出口条件（满足才准入下一阶段） |
|---|---|---|
| `strangers` | 陌生人 | 双方在各自的故事线里，尚未产生对对方的具体印象 |
| `first_meeting` | 初遇 | 有过一次带**身份差**的会面，双方各留下一个偏颇的第一印象 |
| `acquaintances` | 相识 | 因事反复接触，能叫出名字、知道对方的处境 |
| `reluctant_allies` | 被迫同盟 | 有一个共同的外部压力让他们必须合作（催化剂要写明） |
| `growing_respect` | 生敬 | 看见对方**做到一件自己做不到的事**（转折点要写明） |
| `denial` | 否认 | 意识到情感但拒不承认，并做出具体的抵抗行为 |
| `tension` | 张力 | 靠近—后退反复，有 almost-moment（差一点就成了）≥2 次 |
| `confession_or_revelation` | 表白/揭露 | 谁先开口、什么情境、结果如何（可逆 or 不可逆） |
| `together` | 在一起 | 关系状态已公开 + 写清仍存在的持续挑战 |

### 可复制模板

```markdown
# 感情线 · {A} × {B}
类型：slow_burn ｜ 目标：第 {200} 章前后定稿关系 ｜ 当前阶段：{tension} ｜ 热度：slow_burn
起始章：第 {41} 章 ｜ 当前章：第 {NNN} 章

## 阶段进度
| 阶段 | 起章 | 止章 | 关键 moment |
|---|---|---|---|
| first_meeting | 41 | — | {他当众失态，她看见了} |
| tension | 88 | — | {almost-moment 1} / {almost-moment 2} |

## 台账
| 类型 | 内容 | 章节 | 状态 |
|---|---|---|---|
| 阻碍 obstacle | {家族阻力} | 62 | 未解除 |
| 吃醋触发 jealousy | {看到第三者的场合} | 74 | 已发酵 |
| 误会 miscommunication | {没说出口的那件事} | 80 | **第 85 章前必须澄清** |

## moment 流日志
| 章节 | 发生了什么 | 关系位移 |
|---|---|---|
| 第 74 章 | {一起淋雨后他把自己的衣服给了她} | 称呼从"先生"变成名字 |
```

**两条硬纪律**：① 误会有**期限**（超过两章不澄清，读者会判角色为蠢）；② 每章的感情推进必须能落到**可见位移**（称呼、距离、谁先看谁），不许只写"心里觉得不一样了"。
